# Liquid Navigation Bar

一个可直接复制使用的 React 液态玻璃导航栏与组件实验室。

在线体验：[bar.fzp.me](https://bar.fzp.me/)

## 快速开始

```bash
npm install
npm run dev
```

打开以下地址：

- `http://127.0.0.1:5173/?playground`：组件实验室与实时参数
- `http://127.0.0.1:5173/?demo`：全屏概念展示
- `http://127.0.0.1:5173/`：基础组件示例

## 模板位置

可复制组件位于：

```text
src/components/liquid-nav/
```

该目录已经包含组件、专属样式、类型导出和独立使用文档。复制到其他 React
项目后，安装 `motion` 与 `lucide-react` 即可使用。

详细说明见 [`src/components/liquid-nav/README.md`](src/components/liquid-nav/README.md)。

也可以直接解压项目根目录中的
`FZP-Liquid-Navigation-Template.zip`，将文件夹放入目标项目。

## 命令

```bash
npm run dev
npm run build
npm run preview
```
